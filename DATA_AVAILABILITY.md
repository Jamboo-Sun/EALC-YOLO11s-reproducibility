# Data Availability / 数据与代码可用性声明

The public Nighttime Pothole Dataset (NPD) can be obtained from the [dataset authors' repository](https://github.com/hhaozhang/NPD). The dataset is described by [Ling et al.](https://doi.org/10.3390/electronics13193790). The study's split manifest, overlap audit, and main-model code and configuration are available in the [EALC-YOLO11s repository](https://github.com/Jamboo-Sun/EALC-YOLO11s-reproducibility). The manifest identifies samples from the study archive by relative path and SHA-256 hash. Reconstructing the exact split requires access to the original study archive.

公开的夜间坑洼数据集 NPD 可从[原作者仓库](https://github.com/hhaozhang/NPD)获取，数据集由 [Ling 等](https://doi.org/10.3390/electronics13193790)介绍。本研究的划分清单、重叠核查报告、主模型代码和配置可从 [EALC-YOLO11s 仓库](https://github.com/Jamboo-Sun/EALC-YOLO11s-reproducibility)获取。划分清单通过相对路径与 SHA-256 哈希标识实验归档样本。恢复原始划分需要获得本研究使用的原实验归档。
